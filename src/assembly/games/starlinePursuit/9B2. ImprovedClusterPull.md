# Improved Step 2 — Structured Cluster Influence

This version:

1. Distributes cluster centers intelligently
2. Pulls stars toward the closest cluster
3. Preserves minimum star spacing
4. Allows isolated stars to remain or be culled

---

# 1. Proper Cluster Center Placement

## Goals

- Spread clusters across the map
- Avoid edges
- Avoid cluster overlap

## Method: Grid-based cluster anchors + jitter

Instead of random picking:

- Divide map into a coarse 3×2 grid
- Pick 1–3 cells randomly
- Place cluster centers in those cells with jitter
- Enforce minimum distance between cluster centers

### Example parameters (320×240)

- Margin: 40 px
- Minimum cluster distance: 80 px
- Cluster count: 2–4

This guarantees:

- Visual distribution
- No edge hugging
- No cluster stacking

---

# 2. Pull Toward Closest Cluster (Distance-Based Influence)

Each star should only respond to the nearest cluster.

## Correct Behavior

For each star:

1. Find nearest cluster center
2. Compute distance `d`
3. If `d < influenceRadius`
   - Apply pull proportional to:

     ```
     strength = (1 - d / influenceRadius)
     ```

   - Multiply by random factor (0.8–1.2)

4. Else:
   - Leave star untouched

This creates:

- Dense core
- Smooth falloff
- Natural boundary

---

# 3. Maintain Minimum Star Distance

After applying pull:

You must enforce spacing.

## Localized Relaxation Pass (Grid-Aware)

Because stars were originally placed using a grid + jitter layout, we already know their approximate spatial partition.

We need to only check stars located in the 3×3 neighborhood of grid cells surrounding the star’s own cell.

**Principle**

Each star belongs to a logical grid cell (gx, gy) used during generation.

When enforcing minimum distance, for a given star only check stars in the 8 adjacent cells.

**Why This Works**

From grid placement:

- Cell size ≈ 50–70 px
- Minimum allowed star distance ≈ 16–20 px
- Jitter ≤ 25% of cell size

Therefore:

- Two stars more than one cell apart cannot overlap
- Only neighbors in adjacent cells can become too close
- This makes the constraint local.

This prevents:

- merged stars
- tiny overlapping clusters
- broken lane generation
