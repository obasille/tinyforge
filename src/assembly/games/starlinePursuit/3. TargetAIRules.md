## Target AI Decision Rules (Movement and Evasion Model)

This section defines how the target chooses its next move each turn. The goal is to produce behavior that is:

- predictable enough to reason about
- uncertain enough to stay challenging
- reactive to player actions
- different across target types
- resistant to trivial camping

The target should feel like it has intent, not randomness.

---

# 1. Core Principle

Each turn, the target evaluates its possible next systems (neighbors) and assigns each a **score**.

It moves to the system with the best score, with some controlled randomness.

So the player is not guessing blindly, but forecasting tendencies.

---

# 2. Candidate Moves

On each turn, the target considers:

- staying in place (optional, rare)
- moving to any directly connected neighboring system

Usually movement is mandatory unless a behavior allows “loitering.”

---

# 3. Scoring Factors (The Universal Rule Set)

Every candidate neighbor system receives points from these factors:

---

## A. Distance From Interceptor (Avoid Capture)

The target strongly prefers systems that increase distance from the capture ship.

- If a move reduces distance → heavy penalty
- If it increases distance → strong bonus

This ensures the target actively flees instead of drifting into capture.

---

## B. Detection Risk (Avoid Sensor Coverage)

The target dislikes moving into areas that are likely watched.

Risk sources:

- beacon radius
- drone patrol zones
- systems adjacent to player scouts
- recently scanned sectors

Moves into watched space are penalized.

This makes sensor placement meaningful.

---

## C. Route Freedom (Avoid Dead Ends)

The target prefers systems with multiple exits.

- Hubs are safer for evasion
- Dead ends are dangerous

This prevents the target from trapping itself unless desperate.

---

## D. Progress Toward Objective (If Goal-Based)

If the target has a destination or mission, it gains bonus for moving closer.

However, this bonus should be moderate, not absolute, so it can reroute under pressure.

---

## E. Terrain Preference (Target Personality)

Different target types value different environments:

- smugglers like trade hubs
- ghosts like nebula zones
- pirates like outer rim ambush systems

This provides identity and learnable patterns.

---

## F. Unpredictability Noise (Avoid Determinism)

To prevent perfect player calculation:

- add small randomness to scores
- or allow the target to sometimes choose the 2nd-best move

This keeps the chase tense.

---

# 4. Base Decision Rule (Generic Target)

A standard target’s priorities:

1. Do not move closer to interceptor
2. Avoid sensor zones
3. Maintain multiple escape routes
4. Make some progress toward escape
5. Add slight unpredictability

This creates fair, readable behavior.

---

# 5. Awareness Levels (Difficulty Lever)

The target should not always have perfect knowledge.

Define awareness tiers:

---

## Tier 0: Blind

Target ignores sensors and player position.
Moves by simple goal-following.

Easy mode.

---

## Tier 1: Instinctive

Avoids interceptor if very close.
Does not anticipate traps.

Normal.

---

## Tier 2: Cautious

Avoids known beacon zones and patrols.
Prefers hubs and freedom.

Hard.

---

## Tier 3: Intelligent

Predicts interception paths.
Actively chooses deceptive routes.

Expert.

---

# 6. Target Archetypes and Their Movement Rules

Each target type uses the same scoring system but with different weights.

---

## 6.1 Smuggler Runner

Personality:

- wants to escape
- prefers busy systems to blend in
- avoids heavy scanning

Rules:

- strong bonus for trade hubs
- moderate objective progress
- high avoidance of beacon coverage

Behavior:

- takes indirect routes if watched
- uses hubs as cover

Player counter:

- watch chokepoints, not hubs directly

---

## 6.2 Pirate Raider

Personality:

- aggressive, not purely evasive
- may loiter to raid

Rules:

- sometimes stays in place in hub systems
- lower avoidance of detection
- prefers outer rim systems

Behavior:

- predictable but dangerous timing

Player counter:

- exploit loiter turns to close distance

---

## 6.3 Ghost Probe

Personality:

- alien, stealth-oriented
- seeks nebula interference

Rules:

- strong bonus for nebula-adjacent systems
- extreme avoidance of scans
- less concern about interceptor distance until close

Behavior:

- slips into fog zones repeatedly

Player counter:

- deploy persistent sensors, not active scans

---

## 6.4 Diplomatic Courier

Personality:

- fast and direct
- less adaptive

Rules:

- very strong objective progress weight
- low avoidance of detection
- occasional double-move burst

Behavior:

- rushes toward exit, can be intercepted by cutoff

Player counter:

- block lanes early, don’t waste scans

---

## 6.5 Decoy Master

Personality:

- survival through deception

Rules:

- may generate false trail events
- sometimes moves into watched space deliberately
- high randomness factor

Behavior:

- hard to pin down, but wastes turns on tricks

Player counter:

- rely on multi-sensor confirmation, not single triggers

---

# 7. Anti-Camping Rules

To prevent trivial endpoint blocking:

---

## A. Exit Choice Is Dynamic

The target does not commit to one escape node until late.

It evaluates multiple exits and shifts if pressured.

---

## B. Escape Requires a Window

Escape is only possible during certain turns.

So camping too early wastes resources.

---

## C. Target Can Abort Escape

If exit is blocked or scanned heavily, target switches plan.

---

## D. Desperation Mode

When cornered, the target may take risky moves:

- run through scanned zone
- enter dead end briefly
- sacrifice stealth for speed

This creates dramatic finishes.

---

# 8. Information the Player Can Learn

The AI is designed so players can infer behavior:

- frequent hubs → smuggler
- repeated nebula dives → ghost
- direct sprint → courier

So the chase becomes:

**classification → prediction → interception**

Not random pursuit.

---

# 9. Example Turn Decision (Illustrative)

Target at System K.

Neighbors:

- Hub L (watched by beacon)
- Quiet M (dead end)
- Corridor N (free, closer to exit)
- Nebula O (scan-resistant)

Target type: Smuggler

Evaluation:

- Hub L: good cover, but beacon risk
- Quiet M: too risky, dead end
- Corridor N: progress bonus, low risk
- Nebula O: neutral preference

Smuggler chooses Corridor N.

Player sees:

- beacon did not trigger
- corridor becomes likely
- interceptor moves to cut off next chokepoint

---

# 10. Summary: What This Achieves

This AI model ensures:

- Target feels intelligent but fair
- Player tools matter (sensors change decisions)
- No single exit camping works
- Different target personalities are readable
- The game is about prediction and trapping

---

The next design layer is: **Trail mechanics** (how long evidence persists, how scouts detect “recent passage”), which is crucial for making the chase feel grounded without giving away exact position.
