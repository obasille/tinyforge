## Complete Content Tables (Ready-to-Build Design Reference)

This section provides concrete, game-ready parameter tables for:

- ships and hardware
- resources and regeneration
- mission presets
- target archetype stats
- map archetypes

These are tuned for a **320×240**, **20–30 star** chase game.

---

# 1. Global Game Parameters

| Parameter            | Value                            |
| -------------------- | -------------------------------- |
| Map size             | 20–30 stars                      |
| Turn limit (typical) | 25 turns                         |
| Target movement      | 1 jump/turn (some exceptions)    |
| Player fleet size    | 3–5 ships max                    |
| Trails persist       | 4 turns (Fresh→Fading→Cold→Gone) |
| CP per turn          | 3                                |
| SE max               | 10                               |
| SE regen             | +3/turn                          |
| Deployment Kits      | 3 (non-regenerating)             |

# 5. Trail Evidence Table

| Trail State | Age       | Player Meaning                  |
| ----------- | --------- | ------------------------------- |
| Fresh       | 0–1 turns | Target passed very recently     |

# 6. Target Archetype Table

## 6.1 Target Movement + Behavior

| ------------------ | ---------- | -------------------- | ----------------------------------- |

## 6.2 Target Awareness Levels

| Tier          | Description                          |
| ------------- | ------------------------------------ |
| 0 Blind       | Ignores player, goal-only            |
| 1 Instinctive | Flees interceptor if close           |
| 2 Cautious    | Avoids beacon/patrol zones           |

Default campaign progression: Tier 1 → Tier 3.
