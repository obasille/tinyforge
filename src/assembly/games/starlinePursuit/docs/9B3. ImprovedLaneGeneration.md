Below is a clean, deterministic **lane generation step with edge-crossing rejection**, designed for:

- ~25–40 stars
- 320×240 map
- small, readable graphs
- no spaghetti intersections

This assumes:

- `Star { x: i32, y: i32 }`
- Stars are already evenly distributed (grid+jitter + clustering)
- `random()` and `randomRange()` exist

---

# Goals

1. Connect nearby stars (k-nearest or radius based)
2. Avoid long branches
3. Reject edges that intersect existing edges
4. Keep graph connected

---

# Data Structures

```ts
class Star {
  x: i32;
  y: i32;
  constructor(x: i32, y: i32) {
    this.x = x;
    this.y = y;
  }
}

class Edge {
  a: i32; // index in star array
  b: i32;
  constructor(a: i32, b: i32) {
    this.a = a;
    this.b = b;
  }
}
```

# Step 1 — Segment Intersection Test

We use standard orientation test.

```ts
function orient(ax: i32, ay: i32, bx: i32, by: i32, cx: i32, cy: i32): i32 {
  return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax);
}

function segmentsIntersect(
  a1x: i32,
  a1y: i32,
  a2x: i32,
  a2y: i32,
  b1x: i32,
  b1y: i32,
  b2x: i32,
  b2y: i32,
): bool {
  let o1 = orient(a1x, a1y, a2x, a2y, b1x, b1y);
  let o2 = orient(a1x, a1y, a2x, a2y, b2x, b2y);
  let o3 = orient(b1x, b1y, b2x, b2y, a1x, a1y);
  let o4 = orient(b1x, b1y, b2x, b2y, a2x, a2y);

  if (o1 == 0 || o2 == 0 || o3 == 0 || o4 == 0) return false; // ignore collinear edge case
  return o1 > 0 != o2 > 0 && o3 > 0 != o4 > 0;
}
```

We ignore collinear edge cases because grid+jitter makes them extremely rare and visually harmless.

# Step 2 — Generate Candidate Edges (k-Nearest)

We connect each star to its nearest neighbors.

Recommended:

- `k = 3`
- max lane length ≈ 90 px

```ts
function distSq(a: Star, b: Star): i32 {
  let dx = a.x - b.x;
  let dy = a.y - b.y;
  return dx * dx + dy * dy;
}
```

---

# Step 3 — Lane Generation with Crossing Rejection

```ts
function generateLanes(stars: Array<Star>): Array<Edge> {
  let edges = new Array<Edge>();
  let n = stars.length;

  let maxDistSq: i32 = 90 * 90;
  let k: i32 = 3;

  for (let i = 0; i < n; i++) {
    // Find nearest neighbors
    let neighbors = new Array<i32>();

    for (let j = 0; j < n; j++) {
      if (i == j) continue;

      if (distSq(stars[i], stars[j]) <= maxDistSq) {
        neighbors.push(j);
      }
    }

    // Sort neighbors by distance (simple insertion sort)
    for (let a = 1; a < neighbors.length; a++) {
      let key = neighbors[a];
      let keyDist = distSq(stars[i], stars[key]);
      let b = a - 1;

      while (b >= 0 && distSq(stars[i], stars[neighbors[b]]) > keyDist) {
        neighbors[b + 1] = neighbors[b];
        b--;
      }
      neighbors[b + 1] = key;
    }

    // Try connecting first k neighbors
    for (let c = 0; c < neighbors.length && c < k; c++) {
      let j = neighbors[c];

      // Avoid duplicate edges
      if (j <= i) continue;

      let valid = true;

      // Check crossing against existing edges
      for (let e = 0; e < edges.length; e++) {
        let e0 = edges[e].a;
        let e1 = edges[e].b;

        // Ignore shared endpoints
        if (e0 == i || e0 == j || e1 == i || e1 == j) continue;

        if (
          segmentsIntersect(
            stars[i].x,
            stars[i].y,
            stars[j].x,
            stars[j].y,
            stars[e0].x,
            stars[e0].y,
            stars[e1].x,
            stars[e1].y,
          )
        ) {
          valid = false;
          break;
        }
      }

      if (valid) {
        edges.push(new Edge(i, j));
      }
    }
  }

  return edges;
}
```
