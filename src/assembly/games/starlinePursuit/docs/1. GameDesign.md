# Game Design Document — **Starline Pursuit**

Space Chase / Deduction Strategy (TinyForge 320×240)

---

## 1. High Concept

**Starline Pursuit** is a turn-based space chase game where the player hunts a moving target traveling along hyperspace lanes between star systems.

The player does not win by identifying the target’s location once, but by:

- building a sensor network,
- predicting movement,
- cutting off escape routes,
- intercepting with a dedicated capture ship.

Core fantasy: **“Corner the target, don’t just follow it.”**

---

## 2. Platform & Presentation Constraints

- Virtual screen: **320×240**
- Entire map visible at once (no scrolling)
- Minimal UI:
  - star network
  - ship icons
  - alerts + short clue log
  - resource bars

---

## 3. Core Gameplay Loop

Each turn:

1. Target moves along star lanes (hidden unless detected)
2. Player receives any sensor triggers
3. Player assigns orders:
   - move ships
   - scan
   - deploy hardware
   - blockade lanes

4. Resources regenerate partially
5. End turn → repeat

Win condition:

- **Interceptor ship enters the same system as the target**

Lose conditions:

- Target reaches an escape node
- Turn limit expires
- Player runs out of operational capability (optional)

---

## 4. Game Resources (Explicit)

All actions consume one or more of these:

### 4.1 Command Points (CP)

Represents fleet coordination per turn.

- Max: **3 CP**
- Refresh: full each turn
- Used for: issuing actions beyond basic movement

### 4.2 Sensor Energy (SE)

Shared power pool for scans and advanced detection.

- Max: **10 SE**
- Regen: **+3 SE/turn**
- Used for: sweeps, deep scans, beacon boosts

### 4.3 Deployment Kits (DK)

Limited physical hardware inventory.

- Start: **3 DK**
- Used for: beacons, relays, decoys
- Non-regenerating (unless mission reward)

### 4.4 Fuel / Mobility Budget (FM)

Limits how often ships can sprint.

- Each ship has Fuel charges
- Regen: slow or none (mission-based)

### 4.5 Time Pressure (Escape Clock)

Target will escape after N turns.

- Typical mission length: **20–30 turns**

---

## 5. Map Design

### 5.1 Typical Map Scale

- **20–30 star systems**
- **2–4 clusters** connected by chokepoints
- Average connections per star: 2–4

### 5.2 Key Node Types

| Node Type   | Description                  | Gameplay Role                   |
| ----------- | ---------------------------- | ------------------------------- |
| Hub System  | 4–5 connections              | High-traffic, ideal for sensors |
| Chokepoint  | Only bridge between clusters | Best interception zones         |
| Nebula Zone | Reduces scan accuracy        | Target hiding area              |
| Trade Relay | Attracts smugglers           | Behavioral anchor               |
| Outer Rim   | Near escape routes           | Late-game danger                |

### 5.3 Escape Nodes

- 1–2 special edge systems
- If target enters → player loses

---

## 6. Player Fleet Assets

Player controls a small task force. Each ship has a clear role.

---

# 6.1 Interceptor Frigate (Capture Ship)

**Purpose:** Only ship that can win the game.

- Movement: **3 jumps/turn**
- Sensor Range: **0 (blind)**
- Actions:
  - Capture (automatic on contact)

Costs:

- Sprint: 1 Fuel
- Cannot scan or deploy

Cooldowns:

- None

Role:

- Must be positioned using intel from other assets.

---

# 6.2 Scout Corvette

**Purpose:** Fast investigation and confirmation.

- Movement: **2 jumps/turn**
- Passive Sensor: detects target if adjacent

Actions:

| Action             | Cost | Time               | Cooldown |
| ------------------ | ---- | ------------------ | -------- |
| Investigate System | 1 CP | 1 turn (must stay) | None     |
| Neighbor Ping      | 1 SE | Instant            | 1 turn   |

Investigation Output:

- “Target passed through recently” (trail)
- “No activity” (eliminate)

Role:

- Flexible mid-game tracker.

---

# 6.3 Survey Cruiser

**Purpose:** Heavy scanning platform.

- Movement: **1 jump/turn**
- Passive Sensor: none

Actions:

| Action                      | Cost        | Time          | Cooldown |
| --------------------------- | ----------- | ------------- | -------- |
| Wide Sweep (sector)         | 4 SE + 1 CP | 1 turn locked | 2 turns  |
| Range Pulse (distance clue) | 2 SE        | Instant       | 1 turn   |
| Deep Scan (strong clue)     | 6 SE + 1 CP | 1 turn locked | 3 turns  |

Role:

- Strategic intelligence, not pursuit.

---

# 6.4 Beacon Layer Tender

**Purpose:** Deploy static sensor network.

- Movement: **1 jump/turn**

Actions:

| Action                  | Cost        | Time    | Cooldown |
| ----------------------- | ----------- | ------- | -------- |
| Deploy Listening Beacon | 1 DK + 1 CP | 1 turn  | None     |
| Boost Beacon Radius     | 2 SE        | Instant | 2 turns  |

Role:

- Controls chokepoints and hubs.

---

# 6.5 Patrol Drone Carrier

**Purpose:** Mobile area coverage.

- Movement: **2 jumps/turn**

Actions:

| Action               | Cost        | Time    | Cooldown |
| -------------------- | ----------- | ------- | -------- |
| Launch Drone Patrol  | 2 SE + 1 CP | Instant | 2 turns  |
| Relocate Patrol Zone | 1 CP        | Instant | None     |

Drone Patrol:

- Covers radius 1–2 jumps
- Lasts 3 turns

Role:

- Flexible mid-game net tightening.

---

# 6.6 Blockade Cruiser (Late Unlock / Optional)

**Purpose:** Deny lanes temporarily.

- Movement: **1 jump/turn**

Actions:

| Action                | Cost | Time         | Cooldown |
| --------------------- | ---- | ------------ | -------- |
| Block Hyperspace Lane | 2 CP | 1 turn setup | 3 turns  |

Effect:

- Target cannot pass that edge next turn
- Forces reroute → interception opportunity

Role:

- Endgame trap closer.

---

## 7. Deployable Hardware

### 7.1 Listening Beacon

- Cost: **1 DK**
- Deploy Time: 1 turn
- Range: radius 1 jump
- Effect: triggers alert if target enters range
- Duration: permanent

Best use: chokepoints.

---

### 7.2 Sensor Relay

- Cost: **1 DK**
- Effect: extends nearby beacon range +1
- Duration: permanent

Best use: hub coverage.

---

### 7.3 Decoy Buoy (Advanced)

- Cost: **1 DK**
- Effect: creates false signal zone
- Duration: 3 turns

Best use: herd target into trap.

---

## 8. Detection & Information Model

Target is normally hidden.

Player learns through:

- Beacon triggers
- Drone sweeps
- Scout investigations (trail)
- Survey scan constraints

Information types:

- Exact detection (rare)
- “Within 2 jumps” zones
- Eliminated sectors
- Recent passage trails

---

## 9. Target Types & Behaviors

Targets differ by movement priorities.

---

# 9.1 Smuggler Runner

- Goal: escape via trade lane
- Prefers: trade relays + hubs
- Avoids: beacon-heavy routes

Behavior:

- Chooses safest high-traffic path

---

# 9.2 Pirate Raider

- Goal: raid then flee
- Prefers: outer rim → hub → rim
- Sometimes stops 1 turn to “loot”

Behavior:

- Predictable but fast

---

# 9.3 Ghost Signal (Alien Probe)

- Goal: reach nebula core
- Prefers: nebula zones
- Harder to scan (scan penalties)

Behavior:

- Moves unpredictably

---

# 9.4 Diplomatic Courier (High-Speed)

- Goal: straight-line escape
- Movement: may move 2 jumps/turn occasionally

Behavior:

- Must be intercepted early

---

# 9.5 Decoy Master (Late Game Boss)

- Drops false trails
- Generates fake beacon triggers occasionally

Behavior:

- Forces player to triangulate carefully

---

## 10. Typical Mission Flow

### Early (Turns 1–6)

- Wide sweeps to locate corridor
- First beacon deployments on chokepoints

### Mid (Turns 7–18)

- Drone patrols tighten net
- Scout confirms likely route
- Interceptor moves into position

### Late (Turns 19–25)

- Blockade closes escape lane
- Beacons trigger final approach
- Interceptor intercepts at hub

---

## 11. Difficulty Controls

- Number of stars (20 → 35)
- Escape timer (30 → 18 turns)
- Target speed boosts
- Sensor energy regen reduction
- More nebula interference
- Decoy targets

---

## 12. UI Layout (320×240)

- Center: star map + lanes
- Bottom: 3–4 action buttons (contextual)
- Top bar: CP / SE / DK / Turn timer
- Side strip: last 3 alerts (“Beacon triggered at Vega”)

---

## 13. Win Experience

A successful game feels like:

- the player predicted the target’s corridor,
- invested in chokepoints,
- forced reroutes,
- and arrived first with the Interceptor.

**Victory is a trap, not a chase.**
