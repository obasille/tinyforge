## UI Flow and Player Interaction Model (320×240)

This section defines how **Starline Pursuit** is played comfortably on a **320×240** virtual screen with minimal clutter, fast decisions, and clear information.

The goal is:

- the map is always readable
- actions are quick to issue
- intel is understandable at a glance
- the player never digs through menus

---

# 1. Core Screen Layout

Single main screen, no mode switching.

### Top Status Bar (20 px height)

Always visible:

- Turn counter + Escape clock
- Resources:
  - CP (Command Points)
  - SE (Sensor Energy)
  - DK (Deployment Kits)

Example:

`Turn 12 / 25   CP ●●○   SE ████░░   DK 2`

---

### Central Map Area (200 px height)

The galaxy graph:

- stars as nodes
- lanes as lines
- ship icons on top of stars
- minimal labels (only key hubs named)

Visual overlays:

- beacon radius rings
- drone patrol zones
- discovered trails

Target is never directly visible unless detected.

---

### Bottom Action Strip (40 px height)

Contextual buttons (max 4 at once):

- Move
- Scan
- Investigate
- Deploy
- End Turn

Buttons are icon + short word.

No nested menus deeper than one level.

---

### Right Intel Feed (optional narrow strip)

Last 3–4 events:

- “Beacon triggered at Vega”
- “Fresh trail found at Hub C”
- “No contact in Sector East”

Short, readable, scroll-free.

---

# 2. Primary Interaction Loop

The player repeats a simple cycle:

1. Select ship
2. Choose action
3. Confirm target system
4. End turn

Everything is 2 taps maximum.

---

# 3. Ship Selection

### Tap a ship icon on the map

Selection highlights:

- ship glow
- reachable systems outlined
- ship info panel appears briefly:

Example:

**Scout Corvette**
Move: 2 jumps
Action: Investigate (1 CP)

Only the essentials.

---

# 4. Movement UI

When “Move” is chosen:

- reachable stars are highlighted
- tap destination star
- movement path animates simply

Movement consumes no CP (basic movement is free).

Sprint options appear as a toggle if fuel is available:

- “Burst Move (+1 jump, Fuel cost)”

---

# 5. Action Menus (One Level Deep)

Each action opens a small radial or pop-up list.

## Scan Menu (Survey Ship)

- Wide Sweep (4 SE)
- Range Pulse (2 SE)
- Deep Scan (6 SE)

Tap one → immediately shows valid targets:

- sector highlight for sweep
- star highlight for pulse

No scrolling.

---

## Investigate Menu (Scout)

- Investigate System (1 CP)
- Neighbor Ping (1 SE)

Tap → select star → result next turn.

---

## Deploy Menu (Tender)

- Listening Beacon (1 DK)
- Sensor Relay (1 DK)
- Decoy Buoy (1 DK)

Tap → select star → deploy.

---

# 6. Information Presentation Rules

The player must never be overwhelmed.

Only show:

- confirmed intel
- recent events
- actionable zones

---

## Trails Display

Trails are subtle:

- Fresh: bright ring
- Fading: dim ring
- Cold: tiny marker

Trails disappear automatically.

Only discovered trails are shown.

---

## Detection Alerts

When target enters sensor range:

A banner appears briefly:

**CONTACT — Beacon at Chokepoint B**

Star flashes once.

Then stored in intel feed.

---

## Uncertainty Communication

Never say “Target is here.”

Say:

- “Strong signal nearby”
- “Recent passage detected”
- “Contact within 2 jumps”

Keeps tension.

---

# 7. Turn Resolution Flow

When player presses **End Turn**:

1. Target moves (hidden)
2. Beacons trigger if applicable
3. Trails update
4. Alerts shown
5. Player regains CP and partial SE

A short “Turn Report” appears:

- “No contacts”
  or
- “Beacon triggered at Vega”

Then immediate control returns.

No long animations.

---

# 8. Target Capture Moment

When Interceptor enters the target system:

Screen pauses with clear message:

**INTERCEPTED — TARGET CAPTURED**

Map zoom pulse + sound cue.

Then mission summary.

---

# 9. Mission Summary Screen (Minimal)

Post-mission shows:

- Turns taken
- Resources used
- Optional objectives completed
- Reward choice (1 of 3)

Example reward options:

- +1 Tech Point
- Unlock Beacon Boost
- +1 Deployment Kit next mission

Simple tap selection.

---

# 10. Readability on 320×240

Key constraints:

- Max 30 stars
- Labels only for hubs/exits
- Icons must be distinct silhouettes
- Overlays are thin and minimal

Avoid:

- text-heavy tooltips
- multiple panels open at once
- large persistent logs

---

# 11. Typical Player Turn Example

Turn 9:

- Alert: “Beacon triggered at Hub Vega”
- Player taps Scout
- Investigate neighboring chokepoint
- Player taps Drone Carrier
- Relocate patrol zone ahead
- Player taps Interceptor
- Move 3 jumps to cutoff hub
- End Turn

Fast, tactical, readable.

---

# 12. Input Priority Design

On tap:

1. Ship selection
2. Action selection
3. Star target selection
4. Confirm/cancel

Always allow:

- one-tap cancel
- back to map instantly

No deep UI states.

---

# Summary

The UI model supports the core fantasy:

- small galaxy always visible
- player makes rapid, meaningful choices
- intel arrives as alerts and fading evidence
- the chase is about prediction and commitment

Everything fits naturally within **320×240** without clutter.
